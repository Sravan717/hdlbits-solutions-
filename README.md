# HDL Bits – Verilog Practice Solutions

This repository contains my solutions to problems from [HDL Bits](https://hdlbits.01xz.net/), 
an online platform for practicing digital logic design in Verilog.

## About

I'm building foundational Verilog skills as part of my M.Tech in Electronic System Design 
and Instrumentation at IIT Madras, with a focus on digital design and VLSI. This repository 
tracks my progress through HDL Bits' problem sets.

## Topics Covered

- Combinational logic (gates, muxes, decoders)
- Sequential logic (flip-flops, counters, shift registers)
- Finite State Machines (FSMs)
- Verilog syntax and module design

## Structure

- `combinational/` — combinational logic problems
- `sequential/` — sequential logic problems
- `fsm/` — finite state machine problems
